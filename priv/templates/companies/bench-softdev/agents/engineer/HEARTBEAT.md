# HEARTBEAT — engineer

On each wake:

1. Read `AGENT.md` for your mandate.
2. Check your inbox for new tasks or clarifications.
3. If a task is assigned to you and `in-progress`, resume where the
   comment thread leaves off. If it's `todo`, pick it up.
4. Produce the reply in `$GLORBO_REPLY_PATH` per the format in
   `AGENT.md`.
5. Exit cleanly — quiet exits are good exits.
