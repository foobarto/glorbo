# Skill: Web Search

## When to Use

When researching libraries, evaluating approaches, checking documentation,
or investigating technical questions that require current information.

## How to Search

Use available web search and fetch tools to:
- Find hex packages for Elixir functionality
- Read library documentation
- Check GitHub issues for known problems
- Compare approaches used by similar projects
- Verify compatibility and version requirements

## Research Report Format

Structure findings as:

1. **Question:** What we needed to find out
2. **Sources:** What was consulted (with links)
3. **Findings:** What we learned, with specifics
4. **Recommendation:** Preferred approach with rationale
5. **Trade-offs:** Pros/cons of alternatives

## Evaluation Criteria

When comparing libraries or approaches:

- **Maturity:** How long has it existed? Active maintenance?
- **Adoption:** Download counts, GitHub stars, community size
- **Compatibility:** Works with our Elixir/Phoenix versions?
- **Simplicity:** How much complexity does it add?
- **Alignment:** Does it fit Glorbo's filesystem-first philosophy?

## Post Results

Post research findings to `.state/inbox.md` addressed to the requesting agent.
If findings affect architecture decisions, also update `.state/decisions.md`.
